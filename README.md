
# 💀 PassiveRoast

**"Because not every thought deserves to be sent."**

PassiveRoast is a funny MCP server that detects passive-aggressive messages and translates corporate drama into human language.

## ✨ Features

- 🔍 Detect passive-aggressive phrases
- 💀 Get a drama score (0–10)
- 🧠 Translate hidden meanings
- ✨ Generate more professional versions
- 💬 Get help replying to awkward situations

## 🚀 Installation

```bash
pip install "mcp[cli]"
```

Run the server:

```bash
python main.py
```

## 🛠️ Tools

| Tool | Description |
|---|---|
| `vibe_check` | Analyze a message |
| `generate_reply` | Get help writing a reply |

## 😂 Example

**Input:**
"Per my last email, as I already said..."

**Translation:**
"I'm getting tired of repeating myself."

**Verdict:**
CORPORATE WARFARE 🥷
